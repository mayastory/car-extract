# conf (rAthena-style)

이 폴더는 **나중에 PHP(임시) → C++ 서버로 분리**할 때 그대로 가져갈 수 있도록, rAthena 느낌의 설정 파일 구조를 미리 만들어 둔 것입니다.

- 현재(단일 PHP)는 이 conf를 **읽지 않습니다** (레이아웃/구조만 제공)
- 추후 서버 분리 시, 모든 **배율/드랍/스폰/포획/경험치/DB 접속** 등을 여기로 이동시키는 것을 목표로 합니다.

## 기본 규칙(제안)
- `rate 100 = 1배` (PokéMMO/rAthena 스타일)
- 클라(브라우저)에서 값을 신뢰하지 않고, 서버에서만 적용/검증

## 파일
- `inter_athena.conf` : DB/서버 접속
- `rates.conf` : 경험치/스폰/포획 등 배율
- `features.conf` : 기능 토글
