Poket Cleaner

1) Run: tools\clean.bat
2) Check cleanup groups
3) Click: "Move selected to tools/_trash" (recommended)
4) If you regret: restore files manually from tools\_trash\<timestamp>\...

Notes
- This tool does NOT touch tools\packege_sync.py
- It never deletes anything unless you press a button.
- "PERMANENT DELETE" is dangerous; prefer _trash.
